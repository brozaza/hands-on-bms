## Deskripsi

Project ini merupakan hasil slicing dari design **Low-Fi Design** yang dibuat di Figma. Design terdiri dari:

1. **Navbar** — Logo/title di kiri, menu navigasi (Home, About, Products, Contact) di kanan.
2. **Hero Section** — Judul besar (TITLE) dengan deskripsi di bawahnya, background gradient.
3. **Tentang Kami** — Section berisi judul dan dua kolom paragraf deskripsi.

## Teknologi
